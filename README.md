# JavaLabworkNumber1
# Работа с матрицами комплексных чисел


- Создание двух матриц с заданным количеством строк и столбцов.
- Сложение матриц.
- Умножение матриц.
- Транспонирование матрицы.
- Вычисление определителя квадратной матрицы.
- Просмотр результата последней операции.


Структура проекта

- `Main.java` — консольный интерфейс программы.
- `Complex.java` — класс для работы с комплексными числами.
- `ComplexMatrix.java` — класс для работы с матрицами.

## Использование

После запуска программа просит ввести количество строк и столбцов, затем значения комплексных чисел для двух матриц.

После этого появляется меню, в котором можно выбрать операцию. Результат выводится в консоль. Можно выполнять несколько операций подряд.
